## Выполненная работа

### Исправленные ошибки кода

1. **UnboundLocalError: Path** (строка 362)
   - Проблема: повторный импорт `from pathlib import Path` в main() создавал локальную переменную
   - Решение: убран повторный импорт, используется верхнеуровневый импорт

2. **NameError: test_pairs** (строка 244)
   - Проблема: `test_pairs` не определена в функции train_calibrator_with_oof()
   - Решение: заменено на `train_pairs` (внутренняя validation внутри train)

3. **Документные группы**
   - Проблема: каждая пара считалась отдельным документом
   - Решение: используются реальные `doc_id` из метаданных (meta.doc_id)

4. **Логика label ответа**
   - Проблема: `pair_label = 1 if labels else 0` - неправильная логика
   - Решение: `pair_label = 1 if any(label_tuple[2] == 1 for label_tuple in labels) else 0`

5. **Неокруглённые риски**
   - Проблема: token_info.get("risk") возвращает округлённые значения до 4 знаков
   - Решение: добавлено поле `raw_risk` в token payload с неокруглёнными значениями

6. **Контроль token control**
   - Проблема: контроль был пропущен, control_results не определён
   - Решение: возвращён verifier.evaluate() и проверка ожидаемых метрик

### Анализ результатов

**Проблема:** Все агрегаторы дают F1=0.0000 и FPR=0.0000 на dev.

**Причины:**
1. Raw scores на dev очень низкие (min=0.015, max=0.115, mean=0.058)
2. Все calibrated scores = 0.4805 (вырождение калибратора)
3. Порог около 0.57, поэтому все predictions = 0
4. Raw AUC около 0.50 - близко к случайному угадыванию

**Интерпретация:**
- Модель на уровне токенов работает хорошо (контроль пройден, AUC=0.8489)
- Модель на уровне агрегации ответов не может различить достоверные и недостоверные ответы
- Raw AUC около 0.50 означает, что агрегированные риски не содержат информации для разделения классов
- Калибратор вырождается, потому что raw scores на dev попадают в область, где isotonic regression не имеет данных

**Возможные причины:**
1. Агрегация токенов теряет информацию, которая есть на уровне токенов
2. Распределение aggregated scores на train и dev сильно отличается
3. Isotonic regression не может экстраполировать за пределы обучающих данных
4. Текущий HF-бандл не подходит для answer-level детекции
