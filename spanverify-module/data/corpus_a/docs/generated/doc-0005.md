Регламент учёта № 5. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для кадровые документы срок ответа на запрос контрагента составляет десять рабочих дней если документ содержит сведения ограниченного доступа.

Для протоколы согласования срок хранения составляет пять.

Для протоколы согласования предельный объём одного вложения составляет пятьдесят мегабайт.

Для первичные учётные документы срок восстановления после сбоя составляет четыре часа.

Для первичные учётные документы предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для акты выполненных работ предельный объём одного вложения составляет двадцать пять мегабайт.

Для акты выполненных работ срок восстановления после сбоя составляет сутки.
