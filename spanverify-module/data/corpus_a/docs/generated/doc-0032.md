Регламент учёта № 32. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для первичные учётные документы периодичность резервного копирования составляет каждый час если срок не продлён решением комиссии.

Для первичные учётные документы срок восстановления после сбоя составляет четыре часа если срок не продлён решением комиссии.

Для листы ознакомления сотрудников срок хранения составляет пять если контрагент подтвердил продление.

Для листы ознакомления сотрудников предельный объём одного вложения составляет десять мегабайт если документ содержит сведения ограниченного доступа.

Для инвентарные карточки периодичность резервного копирования составляет каждый час.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в сутки.
