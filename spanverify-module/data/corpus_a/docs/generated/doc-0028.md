Регламент учёта № 28. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт если документ содержит сведения ограниченного доступа.

Для инвентарные карточки срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для листы ознакомления сотрудников предельный объём одного вложения составляет двадцать пять мегабайт.

Для листы ознакомления сотрудников периодичность резервного копирования составляет раз в неделю.

Для договоры с контрагентами предельный объём одного вложения составляет двадцать пять мегабайт.

Для договоры с контрагентами срок ответа на запрос контрагента составляет пять рабочих дней если срок не продлён решением комиссии.

Для протоколы согласования предельный объём одного вложения составляет десять мегабайт если срок не продлён решением комиссии.

Для протоколы согласования срок ответа на запрос контрагента составляет три рабочих дня.
