Регламент учёта № 33. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для акты выполненных работ срок хранения составляет семь.

Для акты выполненных работ срок восстановления после сбоя составляет трое суток.

Для счета-фактуры предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для счета-фактуры периодичность резервного копирования составляет раз в сутки если иное не установлено договором.

Для вторичные учётные документы периодичность резервного копирования составляет каждый час если срок не продлён решением комиссии.

Для вторичные учётные документы предельный объём одного вложения составляет двадцать пять мегабайт.

Для договоры с контрагентами срок хранения составляет семь.

Для договоры с контрагентами периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.
