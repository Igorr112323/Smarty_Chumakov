Регламент учёта № 42. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры срок хранения составляет десять.

Для счета-фактуры срок восстановления после сбоя составляет четыре часа если документ содержит сведения ограниченного доступа.

Для кадровые документы срок хранения составляет двадцать пять если документ содержит сведения ограниченного доступа.

Для кадровые документы срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней.

Для вторичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для акты выполненных работ периодичность резервного копирования составляет раз в сутки если контрагент подтвердил продление.

Для акты выполненных работ срок восстановления после сбоя составляет два часа если срок не продлён решением комиссии.
