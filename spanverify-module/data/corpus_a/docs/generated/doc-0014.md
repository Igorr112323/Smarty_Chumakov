Регламент учёта № 14. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы срок ответа на запрос контрагента составляет пять рабочих дней если срок не продлён решением комиссии.

Для кадровые документы срок восстановления после сбоя составляет сутки если иное не установлено договором.

Для договоры с контрагентами периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для договоры с контрагентами срок восстановления после сбоя составляет трое суток если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет два часа если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок хранения составляет семь.

Для счета-фактуры периодичность резервного копирования составляет каждый час.

Для счета-фактуры срок восстановления после сбоя составляет трое суток если документ содержит сведения ограниченного доступа.
