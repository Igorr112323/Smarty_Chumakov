Регламент учёта № 8. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы периодичность резервного копирования составляет каждый час если контрагент подтвердил продление.

Для кадровые документы срок ответа на запрос контрагента составляет три рабочих дня если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей предельный объём одного вложения составляет десять мегабайт.

Для журнал регистрации доверенностей срок хранения составляет двадцать пять если контрагент подтвердил продление.

Для первичные учётные документы предельный объём одного вложения составляет десять мегабайт если иное не установлено договором.

Для первичные учётные документы срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для договоры с контрагентами срок ответа на запрос контрагента составляет десять рабочих дней.

Для договоры с контрагентами срок хранения составляет двадцать пять если иное не установлено договором.
