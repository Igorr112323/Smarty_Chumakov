Регламент учёта № 20. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в сутки.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней если срок не продлён решением комиссии.

Для инвентарные карточки предельный объём одного вложения составляет двадцать пять мегабайт если срок не продлён решением комиссии.

Для инвентарные карточки срок ответа на запрос контрагента составляет три рабочих дня.

Для вторичные учётные документы периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.

Для вторичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для договоры с контрагентами срок хранения составляет семь.

Для договоры с контрагентами срок ответа на запрос контрагента составляет пять рабочих дней если срок не продлён решением комиссии.
