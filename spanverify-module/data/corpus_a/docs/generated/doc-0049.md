Регламент учёта № 49. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры срок ответа на запрос контрагента составляет три рабочих дня.

Для счета-фактуры срок восстановления после сбоя составляет трое суток.

Для кадровые документы срок хранения составляет пять если документ содержит сведения ограниченного доступа.

Для кадровые документы периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.

Для инвентарные карточки срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт если иное не установлено договором.

Для листы ознакомления сотрудников периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для листы ознакомления сотрудников предельный объём одного вложения составляет пятьдесят мегабайт.
