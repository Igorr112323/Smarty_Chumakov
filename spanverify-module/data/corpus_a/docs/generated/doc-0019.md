Регламент учёта № 19. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы срок хранения составляет двадцать пять.

Для кадровые документы предельный объём одного вложения составляет двадцать пять мегабайт.

Для вторичные учётные документы срок ответа на запрос контрагента составляет три рабочих дня если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы срок восстановления после сбоя составляет сутки.

Для листы ознакомления сотрудников предельный объём одного вложения составляет пятьдесят мегабайт.

Для листы ознакомления сотрудников срок хранения составляет десять.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт.

Для инвентарные карточки срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.
