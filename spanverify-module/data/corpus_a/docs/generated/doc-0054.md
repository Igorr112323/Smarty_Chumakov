Регламент учёта № 54. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для протоколы согласования срок восстановления после сбоя составляет четыре часа.

Для протоколы согласования периодичность резервного копирования составляет каждый час если срок не продлён решением комиссии.

Для кадровые документы периодичность резервного копирования составляет каждый час если срок не продлён решением комиссии.

Для кадровые документы срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для акты выполненных работ предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для акты выполненных работ срок восстановления после сбоя составляет два часа если иное не установлено договором.

Для вторичные учётные документы срок хранения составляет двадцать пять.

Для вторичные учётные документы периодичность резервного копирования составляет раз в сутки если иное не установлено договором.
