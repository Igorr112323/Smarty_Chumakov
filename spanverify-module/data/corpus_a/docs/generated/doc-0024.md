Регламент учёта № 24. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для протоколы согласования срок ответа на запрос контрагента составляет пять рабочих дней.

Для протоколы согласования предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы периодичность резервного копирования составляет раз в сутки если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней.

Для кадровые документы предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.

Для кадровые документы срок восстановления после сбоя составляет четыре часа если срок не продлён решением комиссии.

Для первичные учётные документы срок хранения составляет двадцать пять если срок не продлён решением комиссии.

Для первичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт.
