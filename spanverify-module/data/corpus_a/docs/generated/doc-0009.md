Регламент учёта № 9. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для вторичные учётные документы срок восстановления после сбоя составляет четыре часа если контрагент подтвердил продление.

Для вторичные учётные документы периодичность резервного копирования составляет раз в сутки.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет три рабочих дня.

Для журнал регистрации доверенностей периодичность резервного копирования составляет каждый час если иное не установлено договором.

Для счета-фактуры предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для счета-фактуры срок восстановления после сбоя составляет четыре часа.

Для кадровые документы периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.

Для кадровые документы предельный объём одного вложения составляет пятьдесят мегабайт.
