Регламент учёта № 58. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры предельный объём одного вложения составляет десять мегабайт если срок не продлён решением комиссии.

Для счета-фактуры срок восстановления после сбоя составляет сутки если срок не продлён решением комиссии.

Для инвентарные карточки предельный объём одного вложения составляет двадцать пять мегабайт.

Для инвентарные карточки срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для протоколы согласования периодичность резервного копирования составляет раз в неделю.

Для протоколы согласования срок хранения составляет двадцать пять если иное не установлено договором.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней.

Для вторичные учётные документы периодичность резервного копирования составляет раз в неделю если иное не установлено договором.
