Регламент учёта № 6. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт если иное не установлено договором.

Для протоколы согласования срок хранения составляет десять если иное не установлено договором.

Для протоколы согласования срок восстановления после сбоя составляет сутки если документ содержит сведения ограниченного доступа.

Для листы ознакомления сотрудников срок ответа на запрос контрагента составляет три рабочих дня если контрагент подтвердил продление.

Для листы ознакомления сотрудников срок восстановления после сбоя составляет трое суток.

Для первичные учётные документы срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для первичные учётные документы срок хранения составляет сорок пять если контрагент подтвердил продление.
