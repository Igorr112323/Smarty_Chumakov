Регламент учёта № 17. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в сутки.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для инвентарные карточки срок восстановления после сбоя составляет трое суток если иное не установлено договором.

Для инвентарные карточки периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.

Для первичные учётные документы срок восстановления после сбоя составляет два часа.

Для первичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней.

Для кадровые документы предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для кадровые документы срок хранения составляет семь.
