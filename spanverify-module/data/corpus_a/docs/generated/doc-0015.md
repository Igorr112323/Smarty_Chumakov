Регламент учёта № 15. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для листы ознакомления сотрудников предельный объём одного вложения составляет двадцать пять мегабайт.

Для листы ознакомления сотрудников срок восстановления после сбоя составляет четыре часа если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы срок хранения составляет семь.

Для вторичные учётные документы предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт.

Для инвентарные карточки срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для договоры с контрагентами срок ответа на запрос контрагента составляет десять рабочих дней.

Для договоры с контрагентами предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.
