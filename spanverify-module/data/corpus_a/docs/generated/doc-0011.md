Регламент учёта № 11. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки срок хранения составляет двадцать пять если документ содержит сведения ограниченного доступа.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для протоколы согласования предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для протоколы согласования срок восстановления после сбоя составляет сутки если иное не установлено договором.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет сутки.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт.

Для акты выполненных работ предельный объём одного вложения составляет десять мегабайт.

Для акты выполненных работ срок восстановления после сбоя составляет четыре часа.
