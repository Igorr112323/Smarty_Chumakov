Регламент учёта № 53. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.

Для инвентарные карточки периодичность резервного копирования составляет каждый час.

Для первичные учётные документы периодичность резервного копирования составляет раз в неделю.

Для первичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для счета-фактуры предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для счета-фактуры срок хранения составляет сорок пять если контрагент подтвердил продление.

Для акты выполненных работ предельный объём одного вложения составляет десять мегабайт если документ содержит сведения ограниченного доступа.

Для акты выполненных работ периодичность резервного копирования составляет каждый час если иное не установлено договором.
