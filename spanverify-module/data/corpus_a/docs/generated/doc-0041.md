Регламент учёта № 41. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для кадровые документы периодичность резервного копирования составляет раз в сутки если иное не установлено договором.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт если контрагент подтвердил продление.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для договоры с контрагентами срок восстановления после сбоя составляет сутки.

Для договоры с контрагентами срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.

Для акты выполненных работ срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для акты выполненных работ предельный объём одного вложения составляет десять мегабайт.
