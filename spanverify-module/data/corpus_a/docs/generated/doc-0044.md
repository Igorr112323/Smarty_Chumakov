Регламент учёта № 44. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры периодичность резервного копирования составляет раз в неделю.

Для счета-фактуры срок хранения составляет пять если срок не продлён решением комиссии.

Для акты выполненных работ предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для акты выполненных работ срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в сутки если иное не установлено договором.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для договоры с контрагентами предельный объём одного вложения составляет пятьдесят мегабайт если контрагент подтвердил продление.

Для договоры с контрагентами срок хранения составляет десять если срок не продлён решением комиссии.
