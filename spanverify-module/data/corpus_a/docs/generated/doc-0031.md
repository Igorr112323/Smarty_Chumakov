Регламент учёта № 31. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для договоры с контрагентами срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для договоры с контрагентами периодичность резервного копирования составляет раз в неделю.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для инвентарные карточки срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для кадровые документы срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для кадровые документы периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.

Для вторичные учётные документы периодичность резервного копирования составляет раз в сутки.

Для вторичные учётные документы предельный объём одного вложения составляет двадцать пять мегабайт если контрагент подтвердил продление.
