Регламент учёта № 40. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для вторичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для вторичные учётные документы предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для акты выполненных работ срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.

Для акты выполненных работ срок хранения составляет пять.

Для инвентарные карточки срок восстановления после сбоя составляет два часа.

Для инвентарные карточки срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для счета-фактуры срок восстановления после сбоя составляет два часа если иное не установлено договором.

Для счета-фактуры периодичность резервного копирования составляет каждый час если контрагент подтвердил продление.
