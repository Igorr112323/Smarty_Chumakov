Регламент учёта № 55. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для протоколы согласования срок восстановления после сбоя составляет два часа если иное не установлено договором.

Для протоколы согласования срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для акты выполненных работ срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для акты выполненных работ срок восстановления после сбоя составляет сутки.

Для листы ознакомления сотрудников периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.

Для листы ознакомления сотрудников срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для договоры с контрагентами срок ответа на запрос контрагента составляет три рабочих дня если документ содержит сведения ограниченного доступа.

Для договоры с контрагентами срок хранения составляет пятнадцать если срок не продлён решением комиссии.
