Регламент учёта № 47. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для договоры с контрагентами периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для договоры с контрагентами срок восстановления после сбоя составляет четыре часа.

Для первичные учётные документы срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.

Для первичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.

Для счета-фактуры предельный объём одного вложения составляет десять мегабайт если срок не продлён решением комиссии.

Для счета-фактуры срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.

Для протоколы согласования срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.

Для протоколы согласования предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.
