Регламент учёта № 18. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для первичные учётные документы срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для первичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней.

Для акты выполненных работ периодичность резервного копирования составляет раз в сутки если иное не установлено договором.

Для акты выполненных работ срок хранения составляет сорок пять если иное не установлено договором.

Для журнал регистрации доверенностей срок хранения составляет семь.

Для журнал регистрации доверенностей предельный объём одного вложения составляет пятьдесят мегабайт.

Для кадровые документы срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для кадровые документы предельный объём одного вложения составляет двадцать пять мегабайт если срок не продлён решением комиссии.
