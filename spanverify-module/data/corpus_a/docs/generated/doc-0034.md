Регламент учёта № 34. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для акты выполненных работ срок хранения составляет пять если контрагент подтвердил продление.

Для акты выполненных работ предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в неделю.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней.

Для вторичные учётные документы срок восстановления после сбоя составляет трое суток если контрагент подтвердил продление.

Для инвентарные карточки периодичность резервного копирования составляет каждый час.

Для инвентарные карточки срок хранения составляет десять если документ содержит сведения ограниченного доступа.
