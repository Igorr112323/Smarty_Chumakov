Регламент учёта № 51. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для счета-фактуры срок ответа на запрос контрагента составляет пять рабочих дней.

Для протоколы согласования периодичность резервного копирования составляет каждый час.

Для протоколы согласования срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для кадровые документы периодичность резервного копирования составляет раз в неделю.

Для кадровые документы срок ответа на запрос контрагента составляет пять рабочих дней если срок не продлён решением комиссии.

Для первичные учётные документы периодичность резервного копирования составляет каждый час если иное не установлено договором.

Для первичные учётные документы предельный объём одного вложения составляет двадцать пять мегабайт.
