Регламент учёта № 29. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для листы ознакомления сотрудников срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.

Для листы ознакомления сотрудников срок хранения составляет пятнадцать.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет два часа если срок не продлён решением комиссии.

Для договоры с контрагентами срок ответа на запрос контрагента составляет три рабочих дня если контрагент подтвердил продление.

Для договоры с контрагентами срок хранения составляет пятнадцать.

Для протоколы согласования срок восстановления после сбоя составляет сутки если срок не продлён решением комиссии.

Для протоколы согласования срок хранения составляет сорок пять если контрагент подтвердил продление.
