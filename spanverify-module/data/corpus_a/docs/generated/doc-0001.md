Регламент учёта № 1. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для вторичные учётные документы срок восстановления после сбоя составляет два часа.

Для вторичные учётные документы предельный объём одного вложения составляет десять мегабайт если иное не установлено договором.

Для первичные учётные документы срок хранения составляет двадцать пять если иное не установлено договором.

Для первичные учётные документы срок восстановления после сбоя составляет четыре часа если контрагент подтвердил продление.

Для акты выполненных работ срок ответа на запрос контрагента составляет три рабочих дня.

Для акты выполненных работ периодичность резервного копирования составляет каждый час.

Для листы ознакомления сотрудников срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для листы ознакомления сотрудников периодичность резервного копирования составляет каждый час если контрагент подтвердил продление.
