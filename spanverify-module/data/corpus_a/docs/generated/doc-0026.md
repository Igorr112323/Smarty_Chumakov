Регламент учёта № 26. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы срок ответа на запрос контрагента составляет десять рабочих дней если срок не продлён решением комиссии.

Для кадровые документы периодичность резервного копирования составляет раз в сутки если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для инвентарные карточки периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт.

Для первичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.

Для первичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.
