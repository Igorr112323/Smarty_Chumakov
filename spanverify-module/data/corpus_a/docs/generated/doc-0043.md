Регламент учёта № 43. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры срок ответа на запрос контрагента составляет пять рабочих дней если срок не продлён решением комиссии.

Для счета-фактуры предельный объём одного вложения составляет пятьдесят мегабайт если иное не установлено договором.

Для протоколы согласования предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для протоколы согласования срок ответа на запрос контрагента составляет десять рабочих дней.

Для вторичные учётные документы срок восстановления после сбоя составляет два часа если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.

Для кадровые документы срок хранения составляет пятнадцать если контрагент подтвердил продление.

Для кадровые документы срок восстановления после сбоя составляет сутки если документ содержит сведения ограниченного доступа.
