Регламент учёта № 21. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры срок хранения составляет пятнадцать если контрагент подтвердил продление.

Для счета-фактуры срок восстановления после сбоя составляет трое суток если документ содержит сведения ограниченного доступа.

Для акты выполненных работ срок ответа на запрос контрагента составляет три рабочих дня.

Для акты выполненных работ предельный объём одного вложения составляет пятьдесят мегабайт если контрагент подтвердил продление.

Для протоколы согласования срок восстановления после сбоя составляет сутки.

Для протоколы согласования периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для инвентарные карточки предельный объём одного вложения составляет двадцать пять мегабайт если контрагент подтвердил продление.

Для инвентарные карточки периодичность резервного копирования составляет каждый час если документ содержит сведения ограниченного доступа.
