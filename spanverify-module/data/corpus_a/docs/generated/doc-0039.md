Регламент учёта № 39. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для договоры с контрагентами периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для договоры с контрагентами срок хранения составляет семь если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей предельный объём одного вложения составляет десять мегабайт если иное не установлено договором.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет три рабочих дня.

Для первичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для первичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для акты выполненных работ предельный объём одного вложения составляет десять мегабайт.

Для акты выполненных работ срок хранения составляет сорок пять если иное не установлено договором.
