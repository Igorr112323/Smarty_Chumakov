Регламент учёта № 36. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для первичные учётные документы срок восстановления после сбоя составляет два часа если срок не продлён решением комиссии.

Для первичные учётные документы периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.

Для кадровые документы срок хранения составляет двадцать пять если срок не продлён решением комиссии.

Для кадровые документы предельный объём одного вложения составляет пятьдесят мегабайт если контрагент подтвердил продление.

Для листы ознакомления сотрудников срок восстановления после сбоя составляет сутки.

Для листы ознакомления сотрудников срок хранения составляет пять если иное не установлено договором.

Для протоколы согласования срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для протоколы согласования предельный объём одного вложения составляет двадцать пять мегабайт.
