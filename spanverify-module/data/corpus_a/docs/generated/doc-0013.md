Регламент учёта № 13. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для акты выполненных работ срок хранения составляет пятнадцать если срок не продлён решением комиссии.

Для акты выполненных работ срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для кадровые документы предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для кадровые документы срок восстановления после сбоя составляет сутки если документ содержит сведения ограниченного доступа.

Для листы ознакомления сотрудников срок ответа на запрос контрагента составляет пять рабочих дней.

Для листы ознакомления сотрудников срок хранения составляет сорок пять если иное не установлено договором.

Для первичные учётные документы периодичность резервного копирования составляет раз в сутки.

Для первичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.
