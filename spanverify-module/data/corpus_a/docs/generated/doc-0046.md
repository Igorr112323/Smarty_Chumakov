Регламент учёта № 46. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для акты выполненных работ срок восстановления после сбоя составляет два часа.

Для акты выполненных работ предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок хранения составляет десять если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для протоколы согласования срок хранения составляет десять.

Для протоколы согласования срок восстановления после сбоя составляет трое суток.

Для вторичные учётные документы срок хранения составляет пятнадцать если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней.
