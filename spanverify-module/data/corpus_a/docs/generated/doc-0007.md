Регламент учёта № 7. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для первичные учётные документы периодичность резервного копирования составляет раз в неделю если документ содержит сведения ограниченного доступа.

Для первичные учётные документы срок хранения составляет семь если контрагент подтвердил продление.

Для вторичные учётные документы периодичность резервного копирования составляет раз в сутки если иное не установлено договором.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней.

Для листы ознакомления сотрудников срок хранения составляет двадцать пять.

Для листы ознакомления сотрудников предельный объём одного вложения составляет десять мегабайт.

Для договоры с контрагентами срок восстановления после сбоя составляет четыре часа если контрагент подтвердил продление.

Для договоры с контрагентами предельный объём одного вложения составляет десять мегабайт.
