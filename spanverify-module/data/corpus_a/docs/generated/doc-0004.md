Регламент учёта № 4. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы срок хранения составляет двадцать пять если контрагент подтвердил продление.

Для кадровые документы срок ответа на запрос контрагента составляет десять рабочих дней если иное не установлено договором.

Для листы ознакомления сотрудников срок хранения составляет десять.

Для листы ознакомления сотрудников периодичность резервного копирования составляет каждый час если контрагент подтвердил продление.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней.

Для журнал регистрации доверенностей срок хранения составляет двадцать пять если документ содержит сведения ограниченного доступа.

Для акты выполненных работ срок хранения составляет двадцать пять.

Для акты выполненных работ периодичность резервного копирования составляет раз в сутки если документ содержит сведения ограниченного доступа.
