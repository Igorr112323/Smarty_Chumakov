Регламент учёта № 22. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для договоры с контрагентами предельный объём одного вложения составляет двадцать пять мегабайт если контрагент подтвердил продление.

Для договоры с контрагентами срок восстановления после сбоя составляет сутки.

Для счета-фактуры срок хранения составляет семь если срок не продлён решением комиссии.

Для счета-фактуры срок восстановления после сбоя составляет сутки если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы срок хранения составляет сорок пять если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы предельный объём одного вложения составляет двадцать пять мегабайт.

Для протоколы согласования срок хранения составляет пятнадцать если контрагент подтвердил продление.

Для протоколы согласования предельный объём одного вложения составляет десять мегабайт если документ содержит сведения ограниченного доступа.
