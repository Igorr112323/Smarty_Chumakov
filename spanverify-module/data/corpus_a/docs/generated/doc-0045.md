Регламент учёта № 45. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы срок ответа на запрос контрагента составляет три рабочих дня если документ содержит сведения ограниченного доступа.

Для кадровые документы срок восстановления после сбоя составляет два часа если иное не установлено договором.

Для договоры с контрагентами периодичность резервного копирования составляет каждый час если документ содержит сведения ограниченного доступа.

Для договоры с контрагентами срок восстановления после сбоя составляет трое суток если документ содержит сведения ограниченного доступа.

Для счета-фактуры срок хранения составляет пятнадцать если документ содержит сведения ограниченного доступа.

Для счета-фактуры срок ответа на запрос контрагента составляет три рабочих дня если контрагент подтвердил продление.

Для журнал регистрации доверенностей предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет трое суток если контрагент подтвердил продление.
