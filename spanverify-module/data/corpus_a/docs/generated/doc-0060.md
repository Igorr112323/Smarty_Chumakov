Регламент учёта № 60. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки предельный объём одного вложения составляет двадцать пять мегабайт если срок не продлён решением комиссии.

Для инвентарные карточки периодичность резервного копирования составляет раз в неделю.

Для договоры с контрагентами срок ответа на запрос контрагента составляет пять рабочих дней если срок не продлён решением комиссии.

Для договоры с контрагентами периодичность резервного копирования составляет раз в сутки если контрагент подтвердил продление.

Для протоколы согласования периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.

Для протоколы согласования срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для кадровые документы срок ответа на запрос контрагента составляет десять рабочих дней если срок не продлён решением комиссии.

Для кадровые документы срок восстановления после сбоя составляет четыре часа.
