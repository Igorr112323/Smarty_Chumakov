Регламент учёта № 38. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки срок хранения составляет семь если срок не продлён решением комиссии.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для вторичные учётные документы срок хранения составляет сорок пять если контрагент подтвердил продление.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней если срок не продлён решением комиссии.

Для протоколы согласования периодичность резервного копирования составляет каждый час если документ содержит сведения ограниченного доступа.

Для протоколы согласования предельный объём одного вложения составляет десять мегабайт.

Для журнал регистрации доверенностей срок хранения составляет десять.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.
