Регламент учёта № 52. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для протоколы согласования периодичность резервного копирования составляет раз в неделю если срок не продлён решением комиссии.

Для протоколы согласования срок ответа на запрос контрагента составляет пять рабочих дней.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет трое суток если иное не установлено договором.

Для журнал регистрации доверенностей срок хранения составляет пять если контрагент подтвердил продление.

Для вторичные учётные документы периодичность резервного копирования составляет раз в неделю.

Для вторичные учётные документы предельный объём одного вложения составляет десять мегабайт если срок не продлён решением комиссии.

Для кадровые документы срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для кадровые документы периодичность резервного копирования составляет каждый час.
