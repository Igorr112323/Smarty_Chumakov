Регламент учёта № 30. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней если документ содержит сведения ограниченного доступа.

Для вторичные учётные документы срок хранения составляет десять.

Для счета-фактуры срок восстановления после сбоя составляет два часа если иное не установлено договором.

Для счета-фактуры срок хранения составляет пять если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок хранения составляет десять.

Для журнал регистрации доверенностей периодичность резервного копирования составляет каждый час если контрагент подтвердил продление.

Для кадровые документы срок восстановления после сбоя составляет четыре часа если документ содержит сведения ограниченного доступа.

Для кадровые документы срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.
