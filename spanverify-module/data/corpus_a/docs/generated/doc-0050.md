Регламент учёта № 50. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет сутки если срок не продлён решением комиссии.

Для счета-фактуры срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для счета-фактуры предельный объём одного вложения составляет пятьдесят мегабайт если срок не продлён решением комиссии.

Для вторичные учётные документы срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.

Для вторичные учётные документы периодичность резервного копирования составляет раз в сутки.
