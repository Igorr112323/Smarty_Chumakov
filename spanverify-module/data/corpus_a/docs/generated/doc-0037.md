Регламент учёта № 37. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для вторичные учётные документы срок восстановления после сбоя составляет трое суток если срок не продлён решением комиссии.

Для вторичные учётные документы срок хранения составляет двадцать пять.

Для листы ознакомления сотрудников периодичность резервного копирования составляет каждый час если контрагент подтвердил продление.

Для листы ознакомления сотрудников срок ответа на запрос контрагента составляет три рабочих дня.

Для счета-фактуры предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для счета-фактуры срок восстановления после сбоя составляет трое суток если контрагент подтвердил продление.

Для акты выполненных работ срок ответа на запрос контрагента составляет десять рабочих дней если срок не продлён решением комиссии.

Для акты выполненных работ срок хранения составляет сорок пять если документ содержит сведения ограниченного доступа.
