Регламент учёта № 35. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для вторичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для вторичные учётные документы периодичность резервного копирования составляет раз в неделю если документ содержит сведения ограниченного доступа.

Для счета-фактуры предельный объём одного вложения составляет десять мегабайт если срок не продлён решением комиссии.

Для счета-фактуры срок хранения составляет двадцать пять.

Для протоколы согласования срок восстановления после сбоя составляет четыре часа.

Для протоколы согласования срок хранения составляет десять если документ содержит сведения ограниченного доступа.

Для первичные учётные документы срок восстановления после сбоя составляет четыре часа если документ содержит сведения ограниченного доступа.

Для первичные учётные документы срок хранения составляет пять если документ содержит сведения ограниченного доступа.
