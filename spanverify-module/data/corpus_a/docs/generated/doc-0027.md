Регламент учёта № 27. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки предельный объём одного вложения составляет двадцать пять мегабайт.

Для инвентарные карточки срок восстановления после сбоя составляет трое суток.

Для первичные учётные документы срок хранения составляет двадцать пять.

Для первичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт.

Для договоры с контрагентами срок восстановления после сбоя составляет два часа если контрагент подтвердил продление.

Для договоры с контрагентами периодичность резервного копирования составляет раз в сутки если иное не установлено договором.

Для кадровые документы срок хранения составляет двадцать пять если срок не продлён решением комиссии.

Для кадровые документы срок восстановления после сбоя составляет трое суток.
