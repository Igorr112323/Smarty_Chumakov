Регламент учёта № 56. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для листы ознакомления сотрудников срок восстановления после сбоя составляет сутки.

Для листы ознакомления сотрудников периодичность резервного копирования составляет раз в сутки если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.

Для договоры с контрагентами срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для договоры с контрагентами срок восстановления после сбоя составляет трое суток если контрагент подтвердил продление.

Для протоколы согласования периодичность резервного копирования составляет раз в сутки.

Для протоколы согласования срок хранения составляет сорок пять если срок не продлён решением комиссии.
