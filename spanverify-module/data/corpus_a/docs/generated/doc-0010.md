Регламент учёта № 10. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для протоколы согласования срок хранения составляет сорок пять если иное не установлено договором.

Для протоколы согласования срок восстановления после сбоя составляет сутки если срок не продлён решением комиссии.

Для первичные учётные документы предельный объём одного вложения составляет десять мегабайт.

Для первичные учётные документы срок восстановления после сбоя составляет сутки.

Для акты выполненных работ предельный объём одного вложения составляет десять мегабайт если иное не установлено договором.

Для акты выполненных работ срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для счета-фактуры срок хранения составляет сорок пять.

Для счета-фактуры периодичность резервного копирования составляет каждый час.
