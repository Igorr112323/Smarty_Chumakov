Регламент учёта № 48. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для кадровые документы предельный объём одного вложения составляет десять мегабайт если контрагент подтвердил продление.

Для кадровые документы периодичность резервного копирования составляет каждый час.

Для акты выполненных работ предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для акты выполненных работ периодичность резервного копирования составляет каждый час.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет пять рабочих дней если иное не установлено договором.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в сутки.

Для первичные учётные документы срок восстановления после сбоя составляет сутки.

Для первичные учётные документы срок хранения составляет двадцать пять если срок не продлён решением комиссии.
