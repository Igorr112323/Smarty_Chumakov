Регламент учёта № 23. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для акты выполненных работ срок хранения составляет семь если иное не установлено договором.

Для акты выполненных работ срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для инвентарные карточки срок восстановления после сбоя составляет четыре часа если контрагент подтвердил продление.

Для инвентарные карточки срок хранения составляет пятнадцать.

Для вторичные учётные документы срок ответа на запрос контрагента составляет пять рабочих дней если контрагент подтвердил продление.

Для вторичные учётные документы предельный объём одного вложения составляет пятьдесят мегабайт если иное не установлено договором.

Для журнал регистрации доверенностей срок хранения составляет сорок пять если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет четыре часа если документ содержит сведения ограниченного доступа.
