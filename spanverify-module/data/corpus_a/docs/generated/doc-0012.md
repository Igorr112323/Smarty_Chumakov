Регламент учёта № 12. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в неделю.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет пять рабочих дней.

Для первичные учётные документы срок восстановления после сбоя составляет трое суток если иное не установлено договором.

Для первичные учётные документы срок хранения составляет десять если контрагент подтвердил продление.

Для кадровые документы периодичность резервного копирования составляет раз в сутки если документ содержит сведения ограниченного доступа.

Для кадровые документы срок восстановления после сбоя составляет сутки если иное не установлено договором.

Для счета-фактуры периодичность резервного копирования составляет раз в неделю.

Для счета-фактуры срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.
