Регламент учёта № 16. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки срок восстановления после сбоя составляет трое суток.

Для инвентарные карточки периодичность резервного копирования составляет раз в сутки если срок не продлён решением комиссии.

Для листы ознакомления сотрудников срок хранения составляет десять если срок не продлён решением комиссии.

Для листы ознакомления сотрудников периодичность резервного копирования составляет каждый час.

Для акты выполненных работ срок восстановления после сбоя составляет четыре часа если документ содержит сведения ограниченного доступа.

Для акты выполненных работ предельный объём одного вложения составляет двадцать пять мегабайт если контрагент подтвердил продление.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт если документ содержит сведения ограниченного доступа.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней если иное не установлено договором.
