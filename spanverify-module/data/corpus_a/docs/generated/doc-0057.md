Регламент учёта № 57. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для счета-фактуры срок ответа на запрос контрагента составляет пять рабочих дней если документ содержит сведения ограниченного доступа.

Для счета-фактуры срок хранения составляет пятнадцать если иное не установлено договором.

Для журнал регистрации доверенностей предельный объём одного вложения составляет двадцать пять мегабайт.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет десять рабочих дней.

Для листы ознакомления сотрудников предельный объём одного вложения составляет двадцать пять мегабайт если иное не установлено договором.

Для листы ознакомления сотрудников срок хранения составляет двадцать пять если срок не продлён решением комиссии.

Для первичные учётные документы периодичность резервного копирования составляет раз в неделю если контрагент подтвердил продление.

Для первичные учётные документы срок восстановления после сбоя составляет четыре часа если иное не установлено договором.
