Регламент учёта № 3. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки предельный объём одного вложения составляет десять мегабайт.

Для инвентарные карточки срок восстановления после сбоя составляет сутки если иное не установлено договором.

Для журнал регистрации доверенностей срок ответа на запрос контрагента составляет три рабочих дня если срок не продлён решением комиссии.

Для журнал регистрации доверенностей периодичность резервного копирования составляет раз в сутки.

Для акты выполненных работ срок ответа на запрос контрагента составляет десять рабочих дней если документ содержит сведения ограниченного доступа.

Для акты выполненных работ срок восстановления после сбоя составляет трое суток если срок не продлён решением комиссии.

Для счета-фактуры предельный объём одного вложения составляет пятьдесят мегабайт если документ содержит сведения ограниченного доступа.

Для счета-фактуры срок ответа на запрос контрагента составляет три рабочих дня если иное не установлено договором.
