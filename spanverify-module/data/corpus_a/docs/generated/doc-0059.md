Регламент учёта № 59. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для инвентарные карточки срок восстановления после сбоя составляет четыре часа если иное не установлено договором.

Для инвентарные карточки срок хранения составляет пятнадцать если срок не продлён решением комиссии.

Для кадровые документы срок восстановления после сбоя составляет трое суток.

Для кадровые документы срок ответа на запрос контрагента составляет десять рабочих дней если контрагент подтвердил продление.

Для журнал регистрации доверенностей срок хранения составляет сорок пять если срок не продлён решением комиссии.

Для журнал регистрации доверенностей срок восстановления после сбоя составляет сутки если контрагент подтвердил продление.

Для вторичные учётные документы срок восстановления после сбоя составляет сутки.

Для вторичные учётные документы срок ответа на запрос контрагента составляет десять рабочих дней если срок не продлён решением комиссии.
