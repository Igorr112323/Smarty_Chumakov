Регламент учёта № 25. Настоящий документ определяет правила учёта и хранения. Он подготовлен генератором корпуса и не является выдержкой из нормативного акта.

Для акты выполненных работ периодичность резервного копирования составляет раз в неделю.

Для акты выполненных работ срок ответа на запрос контрагента составляет три рабочих дня если контрагент подтвердил продление.

Для инвентарные карточки предельный объём одного вложения составляет пятьдесят мегабайт.

Для инвентарные карточки срок хранения составляет пять если срок не продлён решением комиссии.

Для вторичные учётные документы срок хранения составляет двадцать пять.

Для вторичные учётные документы срок восстановления после сбоя составляет сутки если иное не установлено договором.

Для договоры с контрагентами предельный объём одного вложения составляет десять мегабайт.

Для договоры с контрагентами срок хранения составляет десять если контрагент подтвердил продление.
