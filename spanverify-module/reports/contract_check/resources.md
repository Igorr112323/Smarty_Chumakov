# Ресурсы: память, время одного ответа, характеристики машины

Относящиеся к договору требования: Приложение 3, п. 4.1 (7) — «работа на центральном процессоре без
видеокарты; объём оперативной памяти будет измерен при испытаниях и указан в руководстве», и
п. 4.1 (10) — «время обработки одного ответа будет измерено при испытаниях и указано в руководстве».

Инструмент: `spanverify-module/scripts/measure_latency.py` (добавлен этой проверкой; измеряет, ничего
не подбирает, ненулевой код возврата не возвращает) плюс закоммиченный
`spanverify-module/scripts/functional_tests.py`. Сырые числа — в
`spanverify-module/reports/contract_check/latency.json` (там же все 50 пар построчно).

## 2. Время обработки одного ответа

Команда: `cd spanverify-module && python3 scripts/measure_latency.py --pairs 50 --out reports/contract_check/latency.json`
(корпус `data/corpus_a3/pairs.jsonl` — реальные документы; режим `demo`; три прогревочных вызова,
затем 50 измерений однопоточным `Verifier.verify`).

| Показатель | Значение |
|---|---|
| Медиана | **0,0505 с** |
| 95-й перцентиль | **1,5203 с** |
| Минимум / максимум | 0,0089 с / 4,9275 с |
| Среднее | 0,2515 с |
| Длины ответов в токенах | мин 9, медиана 46,0, макс 988 |
| Стоимость токена | 0,403–25,931 мс/токен (медиана длины ответа 46 токенов) |
| Пар измерено | 50 |

Честные границы числа. (1) Это **демо-режим**: признаки считаются лексическими суррогатами, без весов
языковой модели (`spanverify/features.py:20-22`), поэтому время режима `hf` — другая величина, и здесь
она не измерена: `python3 -m spanverify verify --mode hf …` даёт `rc = 2` и
`BackendUnavailable: режим 'hf' требует torch и transformers: pip install -r requirements-hf.txt`
(в песочнице нет ни `torch`, ни весов: `requirements-hf.txt` ставит `torch~=2.14` с
`download.pytorch.org/whl/cpu`, веса — с huggingface.co, оба хоста вне белого списка сети).
(2) Разброс в 554 раза между минимумом и максимумом объясняется длиной: самая длинная пара — 988
токенов ответа на контексте 20 016 знаков — стоит 4,93 с, самая короткая (9 токенов) — 0,0089 с.
(3) Оценку «единицы миллисекунд» из `docs/РУКОВОДСТВО.md:85` эти числа не подтверждают: медиана —
50 мс, а не «единицы».

Для сопоставления — то, что измеряет закоммиченный `scripts/functional_tests.py` (тот же день, та же

## 3. Память

| Что | Значение | Как получено |
|---|---|---|
| Пик резидентной памяти процесса целиком (интерпретатор + пакет + 50 пар) | **36 312 КиБ ≈ 35,5 МБ** | `resource.getrusage(RUSAGE_SELF).ru_maxrss` в `measure_latency.py` |
| Пик голого интерпретатора | 8 056 КиБ | `python3 -c "import resource; …"` |
| Пик после `import spanverify.engine` | 18 200 КиБ | та же команда с импортом |
| Прирост на пакет и разбор 50 пар | 36 312 − 8 056 = 28 256 КиБ | разница двух замеров выше |
| Пик Python-объектов за прогон (одна самая тяжёлая пара даёт тот же максимум) | 4 855,1 КиБ | `tracemalloc.get_traced_memory()[1]` |
| «Загрузка верификатора +0 КиБ» | артефакт метода, а не результат: `ru_maxrss` — монотонный пик, а импорт модуля случается до первой точки замера | `memory_load` в `latency.json` |
| Пик `tracemalloc` при росте контекста | 0,11 → 10,62 МБ (500 → 50 000 знаков) | `scripts/functional_tests.py` |

`torch` и веса модели в этих числах не участвуют: по `requirements-hf.txt` зависимости режима `hf`
в поставку не входят («без torch .exe в разы меньше и стартует без DLL»), а `docs/РУКОВОДСТВО.md:108`
упоминает их объём качественно: «около 500 МБ библиотек и загрузка весов модели при первом запуске»
— цитата, измерением не является.

## 4. Что из этого следует для договора

* «Работа на CPU без видеокарты» — подтверждено: `functional_tests.py` печатает
  `gpu: отсутствует (nvidia-smi не найден)`, `cpu_count: 2`, и весь набор (515 тестов) плюс
  2 000 000-знаковые контексты прошли на этой машине без GPU.
* «Объём ОЗУ … измерен при испытаниях и указан в руководстве» — **не выполнено**: в
  `docs/РУКОВОДСТВО.md` числа ОЗУ нет, а в `docs/ГОСТ/19.505_Руководство_пользователя.md:21` прямо
  записано: «Процессор, память | **не измерено** (`null`): функциональные испытания не проводились».
* «Время обработки … указано в руководстве» — **не выполнено**: `docs/РУКОВОДСТВО.md:85` даёт только
  качественную строку «миллисекунды … на ноутбуке — единицы миллисекунд»; ни медианы, ни 95-го
  перцентиля, ни даты и машины измерения в руководстве нет.
* Числа этого раздела — измерение 2026-10-12 в песочнице, а не оформленные договорные испытания:
  у них нет подписи, методики приёмки и контрольной выборки, подтверждённой человеком
  (`data/review_queue/decisions.jsonl` не создан).
