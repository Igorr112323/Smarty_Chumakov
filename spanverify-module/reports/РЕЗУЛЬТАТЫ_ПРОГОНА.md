## 2. Режим работы с языковой моделью (`hf`)

Режим `hf` **недоступен** в этом окружении: режим 'hf' требует torch и transformers: pip install -r requirements-hf.txt (причина: ModuleNotFoundError: No module named 'torch').

При запросе режима `hf` без зависимостей программа возвращает явную ошибку с кодом 2 и подсказкой `pip install -r requirements-hf.txt`, а не переходит на лексический режим.
