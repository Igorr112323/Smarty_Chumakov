# Отчёты и числа

Здесь лежат отчёты прогонов. Актуальные числа всех документов — в `METRICS.json`
(его собирает `scripts/collect_metrics.py`, сверяет `scripts/check_numbers.py` в CI).

| Файл | Что это |
| --- | --- |
| `METRICS.json` | единый файл чисел: версия, коммит, seed, тесты, покрытие, демо-метрики (отложенная часть и весь корпус), кросс-корпус, пилот, артефакты релиза |
| `cross_corpus.json` | кросс-корпусный тест: обучение на демо-корпусе, оценка на корпусе другого генератора |
| `coverage.json` | машинный отчёт покрытия (создаёт pytest-cov) |
| `demo/report.md` | исторический отчёт по документному корпусу (марка «demo») |
| `experiments/experiment.md` | отчёт `scripts/run_experiments.py` |
| `pilot/pilot.json`, `pilot/pilot.png` | пилот на малой модели (`ruGPT3-small`) на синтетических промтах: числа по слоям и картинка (артефакт CI) |

## Оговорка про кросс-корпус

Кросс-корпусный тест показывает переносимость метода на другой генератор, а не на
реальные регламенты; для реальных нужны 1200 пар. Внутри демо-корпуса token F1
0.953 при FPR 0.002, на втором генераторе — 0.731 при FPR 0.144 (критерий по FPR
там не выполняется).

## Оговорка про демо-числа

Демонстрационный корпус синтетический. Его числа (token F1 0.953, FPR 0.002, строгий
F1 фрагментов 0.283) доказывают работоспособность и самосогласованность конвейера,
а не качество на реальных документах. Научные выводы требует режим `hf` и своя
разметка.
