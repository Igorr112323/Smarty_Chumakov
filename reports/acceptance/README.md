# P6 — приёмочный контур замороженного P5

**Рабочий протокол, не акт приёмки.** Официальный test177 не оценивается. Замороженный бандл: 122874 байта, SHA-256 `e0b13c693a058dfd66ed24a52fc14e9c70964e95885358e7b99cc1f328ad6892`.

## Границы изменений

Нет научного обучения, подбора порогов, переобучения P1/P4/P5 или выбора конфигурации по dev. Пользователь отдельно разрешил существующие тестовые fit/train на synthetic/demo. Их временные модели не становятся продуктом. Код обучения корректируется только для устранения ошибки unit-теста PAVA; это не переобучает сохранённую модель. Полный public replay P5 обязателен до признания изменений допустимыми.

`protocol.json` фиксирует сопоставление режимов **до публикации новых чисел**. P5 token convention — scored-позиции внутри сохранённых фрагментов плюс обязательные правила; исторические P2/P3/P4 результаты не переписываются.

## Инцидент изоляции

Первый, впоследствии остановленный регрессионный прогон вызвал старый тест chunking. Тест сначала парсил **весь** `data/corpus_a3/pairs.jsonl`, затем выбирал первые 20 примеров. Это недопустимое чтение общего корпуса, включающего reserved test177. Официальный модельный прогон/оценка test177 не выполнялись, но утверждать отсутствие чтения было бы неверно. Тест переведён на train, установлен audit hook в `tests/conftest.py`, запрещающий открывать реальный test177 и общий corpus_a3/pairs.jsonl. Все последующие полные прогоны должны работать с этой защитой. Результаты первого прогона не используются как подтверждение приёмки.

## Измерения и поставка

Workflow `p6-acceptance.yml` выполняет actual public saved-dev replay, product-only demo/HF benchmarks и реальные CLI/web/API запросы. Три повтора для cold/warm и двух ролей длинного входа: document-context и answer-text. Скачивание модели вынесено отдельно. Таймауты — цензурированные неуспешные наблюдения, а не медианы успешных запросов. Для диагностики сохраняются cProfile и логи.

Матрица AI-share — программно сгенерированная смесь с известной долей символов, а не доказательство калибровки на настоящих LLM-авторах. `ai_share` относится к недостоверности; `ai_participation` — отдельная оценка стиля. Плохие результаты должны оставаться видимыми.

RC Windows собирается прежним `build-and-release-exe.yml` на windows-latest с сохранением size/autonomy/HTTP проверок. Автоматическое обучение при отсутствии весов заменено отказом. Автоматические коммиты в ветки удалены; результаты — артефакты. Публикация — только prerelease с `--latest=false`, на точный SHA запуска, без stable-обещаний.

### Portable copy / update

Скопировать exe либо распакованный onedir целиком в новую папку; настроек в реестр приложение не записывает. Для обновления остановить процесс, проверить SHA256SUMS и заменить всю папку/файлы из одного RC, не смешивая версии config. Сохранённый frozen-p5.json и p5-runtime.json входят в поставку. По умолчанию маленький exe запускает demo. HF — отдельный режим: внешние веса примерно 530 MB и совместимые библиотеки примерно 500 MB **не включены** в лимит маленького exe; сам факт наличия этих файлов не доказывает Windows HF autonomy. Для HF доступны явные --weights, --model и --runtime-dir; поддержка конкретной внешней раскладки должна подтверждаться отдельным smoke, не объявляется измеренной заранее.

До появления итоговых отчётов и SUCCESS обычного ci.yml P6 **не завершён**, а контракт целиком не принят.
