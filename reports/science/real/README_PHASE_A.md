## Источник и лицензия
- Официальный интернет-портал правовой информации **pravo.gov.ru** (ФЗ, указы Президента, постановления Правительства, приказы ведомств с открытой публикацией)
- Государственные акты не являются объектами авторских прав — **ст.1259 ГК РФ**, зафиксировать в отчёте
- Никаких неофициальных зеркал/агрегаторов, только публичное право доступа

## Сбор (как будет)
- ≥1600 документов, длины 2–50 тыс. знаков (≥10% ≥20 тыс. для длинного хвоста), UTF-8, фильтр <1500 знаков, бинарные/сканы исключить
- Дедуп по sha256 нормализованного текста, запас на фильтры
- Без детекторных/web-поисковых API — только скачивание + локальная обработка
