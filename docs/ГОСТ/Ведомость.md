## 2. Спецификация поставки

| Файл | Размер, байт | SHA256 | Как получен |
|---|---|---|---|
| `spanverify.pyz` | **593 578** | `933ab94a4366b201f7c3a45bb7995780b1c71d7bdb7774372f008b24d4effe11` | собран локально: `python scripts/make_zipapp.py` |
| `spanverify.exe` | `null` | `null` | собирается только на Windows-раннере GitHub Actions; сборка в этом прогоне не выполнялась |
| `spanverify-win.zip` | `null` | `null` | то же |
| `SHA256SUMS.txt` | `null` | `null` | формируется в релизе вместе с `.exe` |

Способ проверки собранного файла:

```bash
cd spanverify-module
python scripts/make_zipapp.py
sha256sum release/spanverify.pyz
python release/spanverify.pyz selftest
```

## 4. Что отсутствует и почему

| Позиция | Причина |
|---|---|
| `.exe` и контрольные суммы к нему | сборка возможна только в GitHub Actions на Windows-раннере; в текущем прогоне job не выполнялся |
| Программа и методика приёмочных испытаний | требует измерить размеры, время и память; измерения не проводились |
| Протокол приёмочных испытаний | требует установки релиза на чистое окружение; релиз не собран |
| Отчёт о патентных исследованиях | патентный поиск не проведён (см. `docs/РИД_полезная_модель/`) |
