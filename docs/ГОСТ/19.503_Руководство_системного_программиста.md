# Руководство системного программиста

**Обозначение документа:** `Smarty_Chumakov.00002-01 90 04-1`
**ГОСТ 19.503-79** «Руководство системного программиста» (структура адаптирована)
**Программа:** SpanVerify, версия 1.3.0 · коммит `39453a6`

---

## 1. Состав и установка компонентов

Программа поставляется в трёх видах:

| Файл | Состав | Требования |
|---|---|---|
| `spanverify.exe` | интерпретатор Python, стандартная библиотека, модуль `spanverify`, веб-интерфейс | Windows x64, Python не нужен |
| `spanverify-win.zip` | то же, но не однофайловая сборка | Windows x64 |
| `spanverify.pyz` | zipapp с модулем | Python 3.10+ |

Сборка `.exe` выполняется только на Windows-раннере GitHub Actions
(PyInstaller кроссплатформенно не собирает исполняемые файлы Windows):
`.github/workflows/build-and-release-exe.yml`.

## 2. Зависимости

| Компонент | Зависимости |
|---|---|
| Ядро, CLI, HTTP API, веб-интерфейс | нет (стандартная библиотека Python 3.10+) |
| Режим `hf` | `torch~=2.14`, `transformers~=5.18`, `sentencepiece~=0.2` |
| Разработка и тесты | `pytest~=9.1`, `pytest-cov~=7.1`, `ruff~=0.16`, `black~=26.5`, `pyinstaller~=6.22` |
| Загрузка источников НПА | `pypdf~=6.1`, системные `poppler-utils`, `tesseract-ocr`, `tesseract-ocr-rus` |

Веса моделей в поставку **не входят**: режим `hf` скачивает их при первом
обращении. В репозиторий веса не коммитятся.

## 3. Сборка

```bash
cd spanverify-module
python -m pip install -r requirements.txt
python -m pytest -q
pwsh scripts/make_exe.ps1        # Windows: сборка .exe
```

Публикация — через GitHub Actions: сборка, смоук-тест (`GET /health`,
`POST /v1/verify` с подменой числа и с подтверждённым ответом), затем
`SHA256SUMS.txt` и релиз. Релиз публикуется только после успешного смоук-теста.

## 4. Конфигурационные файлы

| Файл | Назначение |
|---|---|
| `config/config.json` | параметры конвейера |
| `config/weights.json` | веса свёртки признаков, порог решения, режим |
| `config/head.json` | обученная логистическая голова |
| `config/calibration.json` | калибровка вероятности |
| `config/participation.json` | модель доли участия ИИ |

В автономной сборке (`.exe`) веса берутся из встроенного бандла: это проверяется
смоук-тестом (поле `weights_source == embedded`).

## 5. Сетевые параметры

HTTP-сервис слушает **только loopback** (`127.0.0.1`), порт по умолчанию `8765`;
если порт занят, выбирается свободный и записывается в `port.txt`. Внешний доступ
не открывается: документы и ответы не покидают компьютер.

## 6. Журналирование и персональные данные

Программа не ведёт журнала с содержимым документов и ответов. В `stats` ответа
API попадают только служебные величины (число токенов, риск, признаки), без
исходного текста. Персональные данные программа не обрабатывает и не хранит.

## 7. Обновление и удаление

Обновление — заменить файл новой версией; настройки и веса хранятся рядом с
программой и совместимы в пределах мажорной версии. Удаление — удалить файл
(или папку) программы; записей в реестр и служб не создаётся.

## 8. Контроль целостности

Каждый релиз сопровождается `SHA256SUMS.txt`. Сверка:

```bash
sha256sum -c SHA256SUMS.txt
```

Проверка зависимостей на известные уязвимости — **не проводилась** (`null`):
инструмента аудита в конвейере нет.
