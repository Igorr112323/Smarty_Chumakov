# Техническое задание на разработку программы SpanVerify

**Обозначение документа:** `Smarty_Chumakov.00002-01 ТЗ`
**Программа:** SpanVerify, версия 1.3.0 · коммит `39453a6`

ТЗ фиксирует требования к программе и критерии приёмки. Числа в разделе
«Фактическое состояние» — вывод выполненных команд, источник
`spanverify-module/reports/METRICS.json`.

---

## 1. Наименование и область применения

Программа проверки ответа на соответствие документу-источнику с оценкой доли
участия ИИ. Применяется при работе с нормативными правовыми актами,
регламентами и внутренними документами организаций.

## 2. Основание для разработки

НИР по заявке в АС «Фонд-М» (У-640148). Программа является результатом НИР.
