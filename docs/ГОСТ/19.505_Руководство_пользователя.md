# Руководство пользователя

**Обозначение документа:** `Smarty_Chumakov.00002-01 90 02-1`
**ГОСТ 19.505-79** «Руководство оператора» (структура адаптирована)
**Программа:** SpanVerify, версия 1.3.0 · коммит `39453a6`

---

## 1. Назначение программы

Программа берёт **документ-источник** и **ответ** (языковой модели или
сотрудника) и показывает, какие места ответа документ не подтверждает: подмену
числа, выдуманное утверждение, расхождение со сроком. Всё считается на вашем
компьютере, документ никуда не передаётся.

## 2. Условия выполнения

| Требование | Значение |
|---|---|
| ОС | Windows 10/11 (готовый `.exe`) или любая с Python 3.10+ |
| Процессор, память | **не измерено** (`null`): функциональные испытания не проводились |
| Свободное место | **не измерено** (`null`) |
| Сеть | не требуется |

## 3. Установка (Windows)

1. Скачайте `spanverify.exe` из раздела релизов репозитория.
2. Запустите двойным щелчком. Появится предупреждение SmartScreen — файл не
   подписан сертификатом. Нажмите «Подробнее» → «Выполнить в любом случае».
3. Откроется страница `http://localhost:8765`. Если порт занят, программа
   выберет другой и запишет его в файл `port.txt` рядом с программой.

Альтернативы:

* `spanverify-win.zip` — распаковать и запустить `spanverify-win\spanverify.exe`
  (вариант для антивирусов, не любящих однофайловые сборки);
* `spanverify.pyz` — при наличии Python 3.10+: `python spanverify.pyz server --port 8765`.

## 4. Удаление

Программа не пишет в реестр и не создаёт служб. Удаление — удалить скачанный
файл (или папку `spanverify-win`). Данные пользователя программа не хранит.

## 5. Работа в веб-интерфейсе

1. Вставьте документ-источник в поле «Документ».
2. Вставьте проверяемый текст в поле «Ответ».
3. Нажмите «Проверить».
4. Ниже появятся: вердикт, оценка риска, порог решения и список спорных
   фрагментов — каждый подсвечен в тексте ответа, у каждого указан риск и метка
   (`doubtful` — сомнительно, `likely_hallucination` — вероятно не подтверждено).

Кнопки «Пример: подмена факта» и «Пример: подтверждённый» заполняют поля
демонстрационными текстами: на первом программа обязана найти фрагмент, на
втором — выдать «Ответ подтверждается документом».

## 6. Работа из командной строки

```bash
python -m spanverify verify --answer "Срок хранения составляет 3 года." \
                            --context "Регламент: срок хранения составляет 10 лет."
python -m spanverify server --port 8765
python -m spanverify selftest
python -m spanverify train --dataset data/demo_pairs.jsonl --out config/weights.json
python -m spanverify evaluate --dataset data/demo_pairs.jsonl
```

Команды: `verify`, `train`, `calibrate`, `evaluate`, `selftest`, `server`
(синоним `serve`), `demo`, `config`, `analyze` (историческая ветка).

## 7. Коды возврата команды `verify`

| Код | Значение |
|---|---|
| `0` | ответ подтверждается документом |
| `1` | найдены спорные фрагменты |
| `2` | ошибка вызова: неверный формат, недоступный режим, нечитаемый файл |

## 8. Сообщения программы

| Сообщение | Что делать |
|---|---|
| `режим 'hf' требует torch и transformers: pip install -r requirements-hf.txt` | установить зависимости режима `hf` либо работать в режиме `demo` |
| `не удалось загрузить модель …` | проверить доступ к весам модели или указать другую через `--model` |
| сообщение о формате датасета с указанием строки | привести файл к требуемой схеме: поля `context` и `answer` обязательны |

Программа не выводит трассировки: любая ошибка превращается в понятное
сообщение и код возврата `2`.

## 9. Ограничения, о которых нужно знать

* В поставке — режим `demo`: признаки считаются лексическими суррогатами, а не
  реальной языковой моделью. Это проверка конвейера и интерфейса, а не
  научный вывод о достоверности.
* На перефразированиях качество падает: на корпусе другого генератора token F1
  0,717 при FPR 0,157; на внешних наборах 0,10–0,20.
* Пропуск сведения (чего-то важного нет в ответе) программа **не находит**.
* Для рабочих выводов нужен режим `hf` и калибровка на ваших размеченных парах.

## 10. Контрольные суммы

Сверяйте скачанные файлы с `SHA256SUMS.txt` из релиза. Контрольные суммы
текущей сборки — в документе «Ведомость и спецификация» (`Ведомость.md`).
