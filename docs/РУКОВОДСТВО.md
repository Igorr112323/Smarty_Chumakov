# Руководство пользователя SpanVerify

Документ написан для человека без опыта программирования. Всё, что нужно, —
браузер и файл `spanverify.exe`. Программировать не нужно, ничего
устанавливать тоже.

---

## 1. Что делает программа

Вы даёте ей два текста:

* **документ** — откуда берутся факты (регламент, инструкция, отчёт);
* **ответ** — то, что надо проверить (ответ языковой модели или сотрудника).

Программа показывает, какие места ответа документ не подтверждает: подсвечивает
их и объясняет, почему считает их сомнительными. Например, в документе написано
«срок хранения — 10 лет», а в ответе «3 года» — программа подсветит «3 года» и
предупредит: высокая вероятность недостоверности.

## 2. Как получить программу

1. Откройте страницу релизов:
   `https://github.com/Igorr112323/Smarty_Chumakov/releases/latest`
2. Скачайте **`spanverify.exe`** (это один файл, Python не нужен).
3. Если хотите убедиться, что файл не подменён, скачайте `SHA256SUMS.txt` и
   сверьте контрольную сумму:

   ```powershell
   Get-FileHash .\spanverify.exe -Algorithm SHA256
   ```

   Хеш должен совпасть со строкой для `spanverify.exe` в `SHA256SUMS.txt`.

Есть и два запасных варианта в том же релизе:

* `spanverify-win.zip` — та же программа в виде папки (нажмите
  «Извлечь всё» → запустите `spanverify-win\spanverify.exe`). Этот вариант
  выбирают, если антивирус не любит одиночные исполняемые файлы.
* `spanverify.pyz` — для тех, у кого установлен Python 3.10 или новее:
  `python spanverify.pyz server --port 8765`.

## 3. Первый запуск

1. Дважды щёлкните по `spanverify.exe`.
2. Windows покажет предупреждение **SmartScreen** («Windows защитила ваш
   компьютер»). Это ожидаемо: файл не подписан платным сертификатом. Нажмите
   **«Подробнее» → «Выполнить в любом случае»**.
3. Откроется окно консоли (можно не закрывать) и страница в браузере:
   `http://localhost:8765`. Если браузер не открылся сам — наберите этот адрес
   вручную.
4. Чтобы закрыть программу: закройте окно консоли или нажмите `Ctrl+C` в нём.

Полезные параметры запуска (из командной строки):

```powershell
.\spanverify.exe --port 9000        # другой порт
.\spanverify.exe --no-browser       # не открывать браузер автоматически
.\spanverify.exe --version          # версия
```

Программа работает **только на вашем компьютере**. Никакие тексты никуда не
отправляются: интернет нужен только для скачивания самого файла.

## 4. Как проверить текст за минуту

1. В левое поле вставьте документ (например, пункт регламента).
2. В правое — ответ, который проверяете.
3. Нажмите **«Проверить»**.

Кнопки-примеры заполняют оба поля готовыми текстами: «Пример: подтверждённый»,
«Пример: подмена факта», «Пример: выдумка». На них удобно посмотреть, как
программа себя ведёт, прежде чем проверять свои документы.

## 5. Что означают числа

| Показатель | Что это значит | Как читать |
| --- | --- | --- |
| **Вердикт** | итоговая оценка | «Ответ подтверждается документом», «Есть сомнительные фрагменты», «Высокий риск недостоверности» |
| **Оценка недостоверности** | число от 0 до 1 | чем больше, тем хуже: 0.1 — почти всё подтверждено, 0.9 — ответ плохо опирается на документ |
| **Порог решения** | граница, выше которой ответ считается недостоверным | подобрана на размеченных данных при доле ложных срабатываний ≤ 10 % |
| **Доля спорного текста** | «мягко / жёстко» | мягко — средняя вероятность по словам (не зависит от порога); жёстко — доля слов выше порога |
| **Фрагменты** | найденные спорные места | у каждого — координаты, уровень риска и метка |
| **Метки** | `doubtful` — сомнительно, `likely_hallucination` — высокий риск | «сомнительно» стоит перечитать глазами, «высокий риск» почти наверняка не подтверждено документом |
| **Время обработки** | миллисекунды | на ноутбуке — единицы миллисекунд |

Программа **не выносит приговор**. Она показывает места, которые стоит
перечитать, и делает это одинаково для всех текстов.

## 6. Про красную плашку «ДЕМО-РЕЖИМ»

В скачанном файле включён демонстрационный режим. Это значит:

* признаки считаются лексическими правилами, **без весов языковой модели**;
* веса и порог обучены на **синтетическом** корпусе, а не на ваших документах.

Поэтому числа показывают, что конвейер работает, но **не являются научным
результатом о достоверности конкретного текста**. Так написано и в самом
интерфейсе — это честное предупреждение, а не недоделка.

Что это даёт на практике: программа корректно работает, её можно показать,
проверить интерфейс, обучить на своих данных (раздел 7) и только тогда
использовать для выводов.

## 7. Как перейти на «настоящий» режим

Полноценный режим (`hf`) считает признаки по реальной языковой модели — он
тяжелее (нужны `torch` и `transformers`, около 500 МБ библиотек и загрузка
весов модели при первом запуске).

```bash
pip install -r requirements-hf.txt      # torch, transformers, sentencepiece
python -m spanverify verify \
  --mode hf \
  --answer "Срок хранения первичных документов составляет 3 года." \
  --context "Регламент 343: срок хранения первичных документов составляет 10 лет."
```

Как обучить программу на **своих** документах:

1. Соберите пары «документ + ответ» и разметьте недостоверные места. Шаблон:

   ```bash
   python scripts/make_markup_template.py --out data/мои_пары.jsonl --count 50
   ```

   Откройте файл, впишите реальные пары и разметку (список `labels` — это
   диапазоны символов ответа: `[начало, конец, 1]`).

2. Обучите и откалибруйте:

   ```bash
   python -m spanverify train --dataset data/мои_пары.jsonl --out config/weights.json --seed 42
   python -m spanverify evaluate --dataset data/мои_пары.jsonl
   ```

3. Смотрите на строку «Критерий качества (token F1 ≥ 0.90 при FPR ≤ 0.10)».
   Если написано «НЕ достигнут» — данных мало или разметка шумная; добавьте
   примеров, а порог вручную не подкручивайте (на этом легко обмануть себя).

## 8. Частые вопросы

**Интернет нужен?** Только чтобы скачать файл. Вся проверка идёт на вашем
компьютере.

**Можно проверить конфиденциальный документ?** Да, и это основной сценарий:
тексты не покидают машину.

**Почему один и тот же текст даёт разные оценки?** В демо-режиме — не должен;
если так, это ошибка, сообщите о ней. В режиме `hf` оценка зависит от модели и
весов.

**Это сертифицированный инструмент?** Нет. Это исследовательская разработка.
Она помогает находить неподтверждённые места, но решение принимает человек.

**Программа ошиблась.** Так бывает: она помечает как сомнительное то, что
человек считает нормальным (в демо-режиме — если документ перефразирован).
Именно поэтому результат подаётся как «фрагмент на перечитку», а не как
приговор.

## 9. Как удалить программу

Программа ничего не устанавливает в систему:

1. Удалите файл `spanverify.exe` (или папку `spanverify-win`).
2. Проверьте папку `config` рядом с файлом, если она там появилась — удалите её
   тоже.
3. Ничего в реестре Windows программа не создаёт, службы не регистрирует.

## 10. Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| SmartScreen блокирует запуск | «Подробнее» → «Выполнить в любом случае»; либо возьмите `spanverify-win.zip` |
| Браузер не открылся | откройте `http://localhost:8765` вручную |
| «Порт занят» | программа сама выберет следующий свободный; адрес напечатан в консоли |
| Страница не открывается | посмотрите окно консоли: там напечатан фактический адрес и режим |
| Антивирус удаляет файл | используйте `spanverify-win.zip` (onedir собирается отдельно именно для этого) |
| Нужен разбор для программы-скрипта | используйте HTTP API: `POST http://localhost:8765/v1/verify` (см. `README.md`) |
