## 1. Название программы

**SpanVerify** — программа проверки ответа на соответствие документу-источнику
с оценкой доли участия ИИ.

## 2. Реферат

Программа предназначена для автоматической проверки текста ответа (языковой
модели или сотрудника) на соответствие документу-источнику. Программа принимает
документ и ответ, вычисляет признаки каждого токена ответа, свёртывает их в
оценку риска, выделяет фрагменты ответа, не подтверждённые документом, сужает их
границы до клаузы и выдаёт вердикт, а также оценку доли участия ИИ.

Программа работает локально, без обращения к внешним сервисам. Ядро реализовано
на стандартной библиотеке Python 3.10+; для режима работы с реальной языковой
моделью требуются `torch` и `transformers`.

Результат работы: вердикт по ответу (`grounded` / `doubtful` /
`likely_hallucination`), список спорных фрагментов с символьными смещениями,
оценка риска, порог решения, доля участия ИИ.

## 3. Функциональность (что программа делает)

| № | Функция | Подтверждение |
|---|---|---|
| 1 | Токенизация ответа с непрерывным покрытием и точными смещениями | `spanverify/core.py` |
| 2 | Расчёт признаков в двух режимах (`demo` и `hf`) | `spanverify/features.py` |
| 3 | Локализация спорных фрагментов с сужением границ до клаузы | `spanverify/engine.py::_shrink_to_clause` |
| 4 | Привязка числа ответа к объекту документа (своё число / чужое) | `spanverify/features.py::number_attribution` |
| 5 | Нормализация чисел (включая прописью), единиц измерения и дат | `spanverify/normalize.py` |
| 6 | Калибровка вероятности и порог решения на обучающей части | `spanverify/calibration.py`, `train.py` |
| 7 | Оценка доли участия ИИ | `spanverify/participation.py` |
| 8 | Командная строка (11 команд), HTTP API, встроенный веб-интерфейс | `cli.py`, `server.py`, `webui.py` |
| 9 | Обучение на своих парах и пересчёт калибровки | `python -m spanverify train` |
| 10 | Метрики качества на размеченном корпусе | `python -m spanverify evaluate` |

## 6. Правовая основа использования материалов НПА

Программа при работе с нормативными правовыми актами опирается на п. 6 ст. 1259
ГК РФ: официальные документы государственных органов не являются объектами
авторских прав. Сырые данные чужих бенчмарков (RAGTruth, RusHallu-RAG) в
поставку не входят и в репозиторий не коммитятся.
