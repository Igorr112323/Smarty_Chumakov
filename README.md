# Ветка данных: тексты корпуса v2

Сырьё: официально опубликованные акты, только документы с текстовым слоем PDF.
Лицензионная основа: п. 6 ст. 1259 ГК РФ — официальные документы государственных
органов не являются объектами авторских прав. В рабочую ветку тексты не коммитятся,
чтобы не раздувать клон: в репозитории лежат пары, сплиты и манифест с sha256.
