# Smarty_Chumakov

Рабочая папка проекта: модуль локализации фрагментов текста, написанных ИИ,
пакет промтов для генерации такого модуля силами ИИ и конструктор полей
заявки.

## Что лежит в репозитории

| Путь | Что это |
|---|---|
| [`spanverify-module/`](spanverify-module/) | Рабочий модуль SpanVerify: ядро, CLI, REST API, веб-интерфейс, тесты, отчёты, сборка |
| [`spanverify-module/README.md`](spanverify-module/README.md) | Документация модуля: быстрый старт, метод, результаты, ограничения |
| [`Промты_для_ИИ.md`](Промты_для_ИИ.md) ( + `.docx`) | Пакет из четырёх промтов: собрать приложение, собрать `.exe`, боевой режим и эксперименты, приёмка |
| [`Заявка_поля_и_формулировки.md`](Заявка_поля_и_формулировки.md) ( + `.docx`) | Готовые формулировки по разделам заявки + чек-лист типовых замечаний экспертизы |
| [`tools/md_to_docx.py`](tools/md_to_docx.py) | Конвертер Markdown → DOCX для сопроводительных документов |

## Быстрая проверка модуля

```bash
cd spanverify-module
python -m spanverify selftest     # самопроверка: детектор, калибратор, API
python -m pytest -q               # 84 теста
python -m spanverify serve        # интерфейс: http://localhost:8000
```

## Важное замечание о состоянии папки

В репозитории изначально был только пустой `README.md`: файлы, подготовленные
в предыдущем сеансе (в том числе «исправленная заявка»), до диска не дошли и
восстановлению не подлежат. Модуль, промты и конструктор заявки собраны заново
и проверены; исходная заявка и ТЗ отсутствуют, поэтому исправленная редакция
заявки может быть сделана только после их повторной загрузки.
